## 简介

Han1mePlus 是一个基于 Flutter 开发的 Hanime1 第三方客户端，采用 Material Design 3 设计规范，致力于提供现代化、极度流畅的观看体验。

> 本项目为与 Hanime1 官方无任何关联。

程序支持：

- `Android`
- `Windows`
- `Ios`
- `Macos`
